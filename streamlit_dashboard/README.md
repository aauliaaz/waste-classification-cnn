# Waste Classification Streamlit Dashboard

Dashboard single-page untuk proyek akhir Pengolahan Citra Digital.

## Menjalankan Aplikasi

Jalankan dari root project:

```powershell
streamlit run streamlit_dashboard/app.py
```

Dashboard ini membaca model dan hasil penelitian yang sudah ada di folder `models/` dan `results/`.
Notebook, kode eksperimen, data, model TensorFlow, dan hasil penelitian lama tidak diubah.
