# Waste Classification Streamlit Dashboard

## Cara menjalankan

Jalankan dari root project:

```powershell
streamlit run streamlit_app/app.py
```

Dashboard menggunakan model dan hasil penelitian yang sudah ada di folder `models/` dan `results/`.
File eksperimen lama, notebook, pipeline preprocessing, dan model TensorFlow tidak diubah.

## Konfigurasi yang mungkin perlu diisi

Nama anggota kelompok dapat diubah pada konstanta `GROUP_MEMBERS` di `streamlit_app/app.py`.
URL repository GitHub sudah mengambil remote project saat ini:

```text
https://github.com/aauliaaz/waste-classification-cnn
```
